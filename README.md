Expense Tracker

This is a simple Expense Tracker project made using Python and MySQL.

What this project does

- Add expenses
- View expenses
- Update expenses
- Delete expenses
- Search expenses by category and date
- Store expenses in MySQL
- Analyze expenses using Pandas
- Create graphs using Matplotlib and Seaborn
- Check spending by category and payment method
- Check daily and monthly spending

Technologies Used

- Python
- MySQL
- Pandas
- Matplotlib
- Seaborn

Files

- "mainprogram.py" - Main expense tracker program
- "analysis.py" - Expense analysis using Pandas
- "visualization.py" - Expense graphs and visualizations
- "requirements.txt" - Required Python libraries

How to Run

- First, make sure Python and MySQL are installed.
- Install the required libraries using:
  pip install -r requirements.txt
- Then run the main program:
  python mainprogram.py
- For expense analysis:
  python analysis.py
- For visualizations:
  python visualization.py
